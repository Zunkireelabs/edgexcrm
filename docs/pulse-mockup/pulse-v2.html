Scene 2 — The AI design language (build spec)One visual system for every AI touchpoint. The gradient spark always means "Orca said this". Plain data never uses it.

1 · AI surface (card)

Briefings, coaching, any block written by AI. Blue-tint gradient, 3px spark-gradient top edge, gradient badge.

This week's briefing

Narrative + evidence + link to records.

2 · AI note (inline)

A one-line insight attached to a number, row or chart. At most one per row or card, shown only when significant.

3 · AI flag (row)

The row gets a violet left edge and a soft wash, so your eye lands on it before reading any numbers.

4 · Hover = "why"

Hovering any AI note opens its reasoning and evidence, with a link to the records. Nothing AI-written is a dead end.

5 · AI action

AI proposes and a human approves. The primary button reads "Review & approve", never a silent auto-act.

Dismissals are logged, so Orca learns which insights are noise.

Rules

  • Gradient spark = AI. Never used for plain data.
  • AI cites numbers; it never computes them.
  • Max 1 AI note per row or card, only when significant.
  • Every AI element links to its records.
  • AI off → AI elements disappear, data stays (Scene 3).
