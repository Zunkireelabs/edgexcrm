What this mockup decides (EDGEX-149)

  • Frame: a floating card 497px wide, 8px in from the table edges, 12px corners, Attio's shadow. It covers the table instead of squeezing it; the selected row stays tinted. Esc closes. Expand opens the full record.
  • Navigation: previous/next buttons plus K/J, and "n of N in <view>" (N is the server total). At the edge of a page it fetches the next page instead of stopping.
  • Highlights (education): Stage · status, Next step, Last touch, Counsellor, Study plan (countries · intake, then level · course · best test score), Ready to apply. "Ready to apply" uses exactly the same check as moving a lead into Applications, so the two can never disagree.
  • Amber only means "act": no next step, last touch past the tenant's follow-up threshold, missing fields for applying, overdue tasks. Nothing else is coloured.
  • Edit in place: Stage (stage + status picker, Attio dropdown from Dialogs v1), Counsellor (managers, or people whose role lets them assign leads; others see a lock on hover), Next step (adds a task). Other cards are read-only and open the full record.
  • Quick actions: Email, Call (tel:), WhatsApp (opens the counsellor's own WhatsApp via wa.me, same as the lead page's contact card today; nothing is sent by EdgeX), Task, Note. Task checkboxes complete the task in place.
  • Intake: from the lead's form answer (preferred intake) or, once applications exist, the earliest application intake. "Intake not set" is shown plainly because it is the deadline driver.
  • Orca later (EDGEX-118): one line above Highlights is reserved for Orca's suggested next step. Not built in this round.
  • Tabs (Attio, measured): 28px items, 8px radius, 16px icon + label 14/20/500. Inactive rgba(0,0,0,.63) with no box. Hover: ink + 1px #eeeff1 ring. Active: ink, #fbfbfb fill, 1px #eeeff1 ring, and a 1px ink underline the full width of the tab sitting on the row's bottom border. State 5 shows a hovered Activity tab.
  • Activity timeline (Attio, measured): 16px avatars — people round, system/forms rounded-square (30%) with an icon; rows 23px joined by a 1px × 8px #eeeff1 line centred under the avatar; verb 63% grey; time 12px 50% grey.
  • Empty states (Attio): Activity is never empty — the lead's creation is always an event ("{source or person} created the lead", from created_at when no audit row exists). Tasks always shows its header; with no open tasks it is just "Tasks 0" + "+" and no box (state 3). Applications and Latest note stay hidden when empty.
  • Tabs list: Overview, Activity, Tasks, Notes. the "···" More button (28×28 icon-only, same tab style, tooltip "More") opens Applications, Documents and Check-ins in the full record.
  • Loading while stepping with J/K: name, stage, counsellor and study plan come from the table row instantly; only Next step, Last touch detail, Ready to apply and the lists show skeletons.
  • Education only: the new preview is for education_consultancy tenants. Other industries keep today's panel unchanged (no new design for them); the legacy-tenant check only confirms nothing changed there.
  • Dropped from today's panel: the old Status badge, Checklist, the big Created/Source/Location fields (now one muted footer line), uppercase labels, the duplicate "View record".
